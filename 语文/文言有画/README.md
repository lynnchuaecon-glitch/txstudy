# 文言有画

面向家庭共读的古诗文水墨绘本书架，目前收录二十篇，从《桃花源记》到《木兰诗》。每篇包含分幕插画、原文、重点字词注音与解释、可展开的白话和共读提示，以及留给孩子填写的读后记录。

## 阅读

下载或克隆仓库后，用浏览器打开本目录的 [打开书架.html](打开书架.html)，即可搜索篇名、作者和关键词，按朝代、主题挑选绘本。

每册的 `篇名·水墨学习绘本.html` 已内嵌插画、样式和脚本，可以独立离线阅读。跨篇跳转需要保留目录结构，资料来源链接需要联网。GitHub 文件页展示源码；请下载到本地后打开 HTML 阅读。

读后记录保存在当前浏览器，不随仓库或离线包上传。重要记录可以在对应绘本中导出。

## 维护与构建

在本目录运行（Python 3，无第三方构建依赖）：

```sh
python3 build_library.py
```

这会更新书架、二十篇独立 HTML，以及 `文言有画·离线阅读包.zip`。分享离线包时，先完整解压，再打开书架。

- `catalog.json`：篇目顺序、分类和入口登记表。
- `shared/`：共用阅读器与书架的模板、样式和交互。
- 各册 `source.json` 或 `index.html`、`book-data.js`：内容源文件，具体维护入口见 [使用与续编说明](使用与续编说明.md)。
- 各册 `assets/`：PNG 制作原图、JPG 阅读图片和小封面。
- 各册 `image-prompts.json`：插画提示词与制作记录；记录中的原始绝对路径仅用于追溯，阅读和构建使用项目内文件。
- `qa/`：内容校核、浏览器检查记录与已有检查脚本。

Git 保留源码、插画原图、阅读图片和可直接打开的成品 HTML。可重新生成的 ZIP、视觉检查截图、临时检查页面、生成中间响应与系统缓存留在本地，不纳入版本控制。浏览器检查脚本中的运行环境路径需按本机安装位置调整。

## 共读方式

先看画、读原句，再让孩子观察、解释与提出问题；白话和深入说明按需展开。插画属于文学想象，版本与来源在各册资料页说明。读后记录不预填，也不把绘本制作完成当作孩子已经掌握。
