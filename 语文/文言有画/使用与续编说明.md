## 保存和分享

日常阅读保留书架与各篇文件夹的位置即可。分享整套时使用 `文言有画·离线阅读包.zip`，先完整解压，再打开其中的 `打开书架.html`。压缩包只有阅读文件，不携带制作原图和源码。

每篇的 `篇名·水墨学习绘本.html` 都内含插画、样式和交互，也可单独发送和阅读；单篇脱离书架文件夹后，“返回书架”和上一篇、下一篇需要相邻文件才可使用。正文阅读无需网络，资料来源链接需联网。

孩子填写的读后记录按篇分别保存在当前浏览器。移动文件、更换浏览器、设备或使用隐私模式，可能使记录无法恢复；重要内容请在各册的“读后”页导出。阅读包不包含孩子的个人记录。

## 为什么采用这个结构

统一书架提供一个固定入口，每篇仍是独立文件。书架只内嵌小封面与篇目资料，不装入所有篇章的大图；点进某篇才打开那一册。新增到 50 篇以内时，不会要求先加载整套绘本。单册仍方便备份、分享和单独修改。

文字几乎不占体积，主要体积来自图片。制作原图保存在各册 `assets/*.png`，阅读版使用 1536 × 1024 的 JPG，保持画幅，不裁切正文插画。书架使用独立的小封面。当前文件大小见 `qa/build-report.json`；后续会随插画内容变化，不承诺每册固定大小。

## 源文件与续编

- `catalog.json`：唯一的篇目登记表，包含顺序、标题、作者、朝代、主题、关键词、文件名与幕数。
- `shared/reader.css`、`shared/reader.js`：所有绘本共用的布局和交互源码。
- `shared/shelf.template.html`、`shared/shelf.css`、`shared/shelf.js`：书架结构、样式和筛选逻辑。
- 各册 `index.html`：封面、读后讨论和资料说明；`book-data.js`：分幕原文、注音、释义和共读内容。
- 第六至第二十册的 `source.json` 是文字源文件，包含封面资料、分幕、字词和共读。构建时由 `prepare_source_book.py` 配合 `shared/source-book.template.html` 自动生成本册 `index.html`、`book-data.js` 和 `frontmatter.json`；这十五册请改 `source.json` 后重建。
- 各册 `image-prompts.json` 与 `assets/`：水墨画提示词、原图和网页用图。
- `build_library.py`：重新生成书架、所有单篇 HTML 和整套离线压缩包。`catalog.js` 与成品 HTML 是生成文件。

续编时先核对原文、读音与版本，再根据文章安排分幕，不固定为六幕或八幕。为新册设置唯一的 `BOOK.slug`，并让它与登记表的 `id` 一致，避免混用读后记录。`textGroups` 按原文自然段登记各幕的零起始序号；可用 `colophon` 保留独立的篇末纪年，全文会另起一段，末幕也会呈现。每幅网页插画按 `01.jpg` 起连续编号，另准备 `shelf-cover.jpg`。

《田忌赛马》的可选排马实验使用本册 `race.js` 与 `race.css`；`race.fragment.html` 保留初始制作片段，实际页面结构在 `index.html`。数字只用于比较模型，不是史料速度。其他册不会加载这个实验。第三至第五册的 `frontmatter.json` 保留制作资料，实际构建仍读取 `index.html` 和 `book-data.js`，不是从 frontmatter 自动再生成页面。

在本目录运行：

```sh
python3 build_library.py
```

原来各册的 `python3 build_portable.py` 入口仍可使用，现会更新整套，确保上一篇、下一篇和书架同步。不要只修改成品 HTML，否则重建时会覆盖。

每次新增后检查：原文拼接完整、自然段正确、字词语境准确、各幕图像符合叙事、全文与折叠内容可用、返回书架和跨册跳转正确、窄屏无横向溢出。共享交互改动还应回看已有册目。

## 共读原则

一幅画、一小段原文、一个值得想的问题。白话和深入赏读按需展开；人物情绪与寓意允许孩子用原文依据作不同解释。插画是文学想象，不作为历史实景或实验记录。读后感留空，不预填孩子的反思，也不把课件制作完成当作孩子已经掌握。
