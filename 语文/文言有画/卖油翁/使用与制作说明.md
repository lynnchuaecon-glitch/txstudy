# 文言有画 · 第二册《卖油翁》

制作日期：2026-10-29。

打开 `卖油翁·水墨学习绘本.html` 可单独阅读，也可从上一级的 `打开书架.html` 进入。

## 阅读内容

六幕依次为善射自矜、微颔不语、问答之间、覆钱于口、徐酌成线、笑而遣之。每幕有水墨画、原文、重点字词的拼音和语境释义；白话、文字赏读与大人提示默认折叠。支持选幕、图片放大、注音开关、大字和字词查找。35 则注释包含“尔”“以”的不同用法。

“全文”按通行课文保留两段，并另设折叠的原作末句补读：“此与庄生所谓解牛斫轮者何异？”说明原作版本中“尧咨善射”和“斵”等文字差异。正文版本和来源见绘本“资料与说明”：

- [维基文库《卖油翁》](https://zh.wikisource.org/zh-hans/賣油翁)
- [古诗文网通行课文文本](https://www.gushiwen.cn/shiwenv_2e3bc3aa2f6b.aspx)

共读围绕原文的动作和语气，不替孩子断定陈康肃公最后的“笑”只有一种含义。认可他的射箭技艺，也分开观察自矜与本领。文中没有写老人会射箭、陈康肃公拜师或道歉，不把这些补写成事实。“熟能生巧”是常用概括，不冒充原文四字句。

读后页留给孩子自己的话；重要记录可导出。保存说明和整套续编方法见上一级 `使用与续编说明.md`。

## 插画与制作文件

六幅插画使用内置 `image_gen` 工具生成，未调用外部 API 生图脚本。准确提示词和原输出路径保存在 `image-prompts.json`；已复制到本册的最终原图为 `assets/01.png` 至 `assets/06.png`。网页版使用同名 JPG（1536 × 1024，完整画幅），书架小封面为 `assets/shelf-cover.jpg`。

人物服饰、庭院和器物是水墨艺术想象，特别检查了担子放下、覆钱位置、油流穿孔、微笑离开等叙事关系。铜钱的尺寸、葫芦造型等不能作为精确考据或实验数据。

`book-data.js` 保存本册的内容，`index.html` 保存页面结构；布局和交互使用上一级 `shared/reader.css` 与 `shared/reader.js`。编辑源码后运行 `python3 build_portable.py`，会同步生成整套离线书架与各册成品。`qa/` 保存验收预览。
