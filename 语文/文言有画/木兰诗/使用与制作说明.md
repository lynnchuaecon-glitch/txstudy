# 木兰诗 · 水墨学习绘本

本册为文言有画第二十册，共九幕，保留全文七段。从上级目录 `打开书架.html` 进入，或直接打开 `木兰诗·水墨学习绘本.html`。

采用常见课文全文，按诗行排版。“惟／唯”“帖／贴”“火伴／伙伴”及“愿驰千里足”等版本说明见书内资料页。作者署佚名，朝代归北朝；郭茂倩是《乐府诗集》的编者，不是本诗作者。

文字在 `source.json` 中维护；内容包括原文、字词、白话、观察问题与家长参考。白话、赏读和深入讨论默认折叠，读后记录保持空白。共读关注人物的承担与选择，以及反复、铺排、互文和详略如何塑造人物，不将诗中虚数当作精确纪年，不将双兔比喻当作动物鉴别方法。

九幅插画由内置 image_gen 生成，属于文学想象。完整提示词与路径在 `image-prompts.json`，原图为 `assets/*.png`，阅读用图为 `assets/*.jpg`，小封面为 `assets/shelf-cover.jpg`。插画总览在上级 `qa/木兰诗插画总览.jpg`。

运行 `python3 build_portable.py` 会重建整套书架、单篇 HTML 与离线阅读包。单篇包含图片和交互，正文无需联网；资料来源链接需联网。分享整套时解压上级目录的 `文言有画·离线阅读包.zip`，再打开书架。

读后记录按篇保存在浏览器；重要记录请导出，不会随阅读包分发。制作验证不代表孩子已学习或掌握。
