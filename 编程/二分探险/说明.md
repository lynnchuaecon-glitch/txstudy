# 二分探险指南

主文件：[二分探险指南.html](二分探险指南.html)。与递归探险指南保持相近的分站式学习结构，可直接在浏览器离线打开。原题链接需要联网。

## 学习路径

- 01—10：从有序、折半、真假序列到不变式、边界函数和复杂度。
- 11—16：定义 check，证明判定，切木条、顺序分组、最大间距与整数安全。
- 17—21：实数精度、图搜索、最短路、截止时间调度、差分。
- 22—26：平均值与比值变换、DP、中位数、LIS、第 K 小计数。
- 27—30：分层调试、离线并行二分选学、远征任务、方法卡。

提高站点需按站首先修知识选学，不以“已备好课件”表示孩子已经掌握；站点不是固定课时。建议每次完成一个小闭环，遇到疲劳及时缩小任务。

## 使用

每站包含概念讲解、2～3 个同根因问题、两层折叠提示、独立验证任务与空白笔记。没有可直接提交的完整 C++ 题解。30 站中有 5 个互动实验、6 个小检查；答对不会自动更改自评。

笔记仅保存在当前浏览器，本地存储键为 `binary-adventure-v1`，与递归讲义分离。导出 JSON 可备份；导入时冲突笔记保留两份文字，已有自评优先。打印包含全部站点、当前笔记和自评；折叠的练习提示不打印，已打开的提示会打印。互动控件不打印，正文保留手推任务。

## 维护

- `build_guide.py`：正文、页面结构与样式。
- `guide.js`：交互、笔记管理与实验逻辑。
- 运行 `python3 编程/二分探险/build_guide.py` 重新生成 HTML。构建使用 Python 标准库，无第三方依赖。
- HTML 内嵌样式与脚本，交付时只需主文件；与递归讲义互跳链接依赖现有相对目录。
