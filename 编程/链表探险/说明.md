# 链表探险指南

打开 [链表探险指南.html](链表探险指南.html)。样式与递归、二分课件相近，HTML 已内嵌样式与脚本，可单文件离线使用；原题与官方参考链接需联网。

## 路线

- 01—10：从卡片、编号与链接出发，单链表、数组模拟、指针与生命周期。
- 11—16：双链、循环链、报数、复杂度，完成三类链表五项基本操作的五级验收。
- 17—19：反转、快慢指针、环、合并与归并排序。
- 20—23：映射定位、最近活跃邻居、离线恢复、撤销栈。
- 24—28：链式前向星、堆与过期候选、按值删点计贡献、后继并查集、动态排名与能力边界。
- 29—30：三档原创独立任务、原题迁移、对拍与孩子自己填写的方法卡。

五级覆盖按家长截图要求设计，第 16 站有逐项对应。提高路线为教学设计，参考入口见首页折叠说明；它不等于完整 CSP-S 课程或掌握认证。图、堆、并查集与树状数组按先修知识选学。

## 引导方式

每站包括概念讲解、2～3 个同主题问题、两层折叠提示、独立产出与空白笔记。部分深入推导放在默认折叠的教练备课区。没有可直接提交的完整 C++ 题解，不预填孩子反思或掌握状态。

5 个实验：沿链接遍历与查找、插入顺序与自环、双链插删、圆环报数、删除与撤销。6 个小检查只反馈判断，不自动修改自评。

每次完成一个小闭环即可；站点不是固定课时。疲劳时停在手推或思路卡，不要求一次读完。

## 保存、迁移与打印

- 本地存储键：`linked-list-adventure-v1`，与其他课件分离。
- 笔记只保存在当前浏览器。移动文件、换浏览器或账号前请导出 JSON。
- 导入校验讲义类型；冲突笔记保留两份文字，已有自评优先。存储失败会提示导出备份。
- 打印输出全部站点及当前笔记、自评；互动控件不打印。默认折叠的练习与教练提示不打印，手动打开后打印。
- 未启用 JavaScript 时可阅读全部正文，实验、分站模式与笔记保存不可用。

## 维护

- `lessons.py`：30 站正文与教学内容。
- `build_guide.py`：首页、导航、样式与 HTML 构建。
- `guide.js`：交互、笔记、导入导出与实验展示。
- `models.js`：实验所用的结构模型。
- `verify_models.cjs`：独立模型对照检查，使用 Node.js 标准库。

重新生成：`python3 编程/链表探险/build_guide.py`。

模型核对：`node 编程/链表探险/verify_models.cjs`。

2026-09-24 已验证：30 站导航、5 个实验、离线 file 页面、笔记持久保存与安全导入导出、打印模式、桌面与手机布局。模型检查包括 20,000 次随机双链修改、逆序撤销、3,000 组围圈报数，以及含重复值和负数的子数组最小值贡献枚举对照。测试使用独立浏览器上下文，不写入孩子的实际笔记。
