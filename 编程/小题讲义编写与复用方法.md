## 四级已经形成的九种方法

### 从作答信号找到真正需要解释的地方

四级同时记录答错和“答对但标了 ☆／△”的题。前者暴露当前偏差，后者提示规则可能不稳。还会关注没有提前标记却做错的题，检查孩子的确定感是否与实际表现一致。

例如，单独问引用能否修改变量时会做，换成结构体参数却又只认指针，讲义据此指出：规则还依赖题面，需要把它迁移到不同类型的对象。这样的诊断决定了后面应比较哪些例子。

复用时，先区分未学、概念不清、过程追踪出错、边界遗漏、换题失灵。没有孩子的作答记录时，只能写知识学习稿与待验证点。

### 跨试卷按共同模型合并

四级把不同卷中的二维数组表达式、函数形参、指针跨度，归到“第一根箭头指向什么、移动单位是什么”这个共同模型；把递推赋值、累乘第一轮和异常跳转，连接到按执行顺序追踪的能力。

每个模块保留原卷题号与回看页，既能看到共同原因，也能回到具体题验证。后续新增失分点时，先判断是旧模型未能调用，还是确实需要增加一个知识点，再决定补哪里。

复用时，课程顺序依据理解依赖和实际卡点安排。题量与频次可帮助分配注意力，不能直接当作未来命题概率。

### 先建立具体模型再引出术语

四级先摆出 a 装着数字、p 装着 a 的位置，再解释取地址与沿地址找回变量；二维数组先画行和格子，再读行指针；文件流先画数据方向，再辨认流对象。

同一套模型在后续章节保持含义一致：普通变量保存数据，指针变量保存位置，引用给原对象增加名字。新知识尽量接在已有模型上，让孩子知道哪些规则继续有效、哪些结构发生了变化。

类比必须交代边界。例如，数组在相关表达式中可以提供首元素的位置，但数组本身不是一个可随意改指向的指针变量；位置起点相同也不代表指针类型相同。

### 把动作与原因连续讲出来

四级指针加减会从起点下标走到终点下标，再区分元素距离与字节差；插入排序会展示元素如何后移、在哪里停止、为什么最后填入那个空位。每一个结论都有前面的过程支持。

这也是“细致”的核心：把初学者无法自行补齐的中间关系写出来。篇幅用在关键推理上，已经解释清楚的动作则交给孩子独立完成。

编写时检查每一句：它所说的对象是否已出现？读者能否知道发生了什么变化？从这个变化到下一句结论，是否还缺一层原因？先走完一个具体例子，再整理一般规则。

### 用最小对比和反例划清概念边界

四级反复比较容易混淆、外形相近的情况：值传递与引用、行指针与二级指针、插入与选择排序、相同地址数值与不同类型。对比围绕一个有区分度的差异展开。

例如，给相等的数加标签，用 `[5a, 5b, 2]` 观察选择排序的一次交换，能直接看见“相等时没有直接互换”仍不足以保证稳定。再让孩子换数据或自己举例，检验她是否抓住了原因。

复用时，每个核心反例都应能回答：它能区分哪两种想法？如果原例无法区分，就换更有诊断作用的例子，而非增加同类题数量。

### 把知识收拢成可执行的检查动作

四级每个模块都把理解落到纸笔动作：

| 遇到的问题 | 孩子能执行的动作 |
| --- | --- |
| 指针或传参 | 画盒子和箭头，指出实际改了哪个对象 |
| 二维数组 | 先指出第一根箭头落在哪里，再看加一跨多远 |
| 互相赋值 | 每执行一行就更新表格，只使用当前值 |
| 排序识别 | 遮住名字，描述这一轮实际完成的动作 |
| 条件遍历 | 先列通过条件的坐标，再累计对应元素 |
| 文件流与异常 | 分别画数据方向和控制流跳转路线 |

动作必须来自已讲清的理由。先解释为什么要保存旧值，再归纳“覆盖前先保存”；先解释为何不能再找到更优候选，再归纳停止条件。

### 用独立新题和延迟复测判断掌握

四级安排“基本掌握验证”和“换题面还能调用吗”两组任务，要求写过程与理由，并配隔日换数抽查。答错后按题号映射回相应模块，避免整份重学。

出迁移题时，要有意识地改变表面条件，例如从普通变量换成结构体、从升序换成降序、从直接问规则换成代码追踪。换数字可检查提取，换对象或表示方式更能检查模型迁移。

判断证据包括无提示完成、能解释关键依据、能处理边界、隔天仍会。四级当时设置的 8/10 等分数门槛属于该套复习安排；后续应根据专题和任务难度调整。

### 分开孩子学习页与家长核对页

四级把讲解、独立任务、自证和留白反思放在孩子页，把核对依据、错因方向、回看位置和提示放在家长页，并要求测试前拆开保管。五级网页进一步将家长附录默认折叠。

家长拿到的应是“该观察什么证据、卡住如何提示、下一步补哪里”。核对依据不用要求孩子逐字背诵；孩子的反思由她自己表达。

讲义可用已讲解的例子帮助建立模型。到了独立任务，给孩子完整的思考空间，提示只在卡住时逐级提供。实时辅导继续遵循“先指出核心问题，再交给孩子一个有意义的任务”。

### 根据学习反馈持续修订并控制负担

四级从集中补几个卡点，发展到跨卷归类、迁移验收与新增补充点。每次出现新作答信号，都可据此调整相应模块。正文同时标明优先级、建议分次学习和疲劳停止条件。

后续家长又提出两项维护要求：已有专题的补充并回原文档；已打印材料修订后明确变动页。这样可以沿着同一份讲义继续学习，减少寻找散落资料的负担。

每次学习以完成一个理解与验证过程为单位。页数、专题数量和资料准备量不自动转成新增作业量。

## 下次编写一个专题的模板

先由教练填写备课信息，再写孩子阅读正文。诊断信息不必全部展示给孩子。

| 备课项 | 需要填写的具体内容 |
| --- | --- |
| 依据与目的 | 原卷题号、实际作答或知识范围；本节要补哪一个能力 |
| 起点 | 孩子已经会什么；哪些还待验证；需要哪项先修知识 |
| 核心卡点 | 最可能混淆的两个模型或动作；如无作答证据，标为待验证 |
| 具体例子 | 最小但足以看见关键变化的对象、数字与情境 |
| 表示与角色 | 用什么图或表；每个变量代表什么；与代码怎样对应 |
| 推演与理由 | 按实际顺序讲变化，说明关键一步为什么成立 |
| 对比与边界 | 一个能暴露错误模型的反例；结论适用的条件 |
| 可执行动作 | 孩子以后遇到相似题，可以先做的一个检查动作 |
| 独立任务 | 一个完整、有意义的分析、修改或验证任务，答案与提示分开 |
| 迁移与复测 | 改变什么表面条件、保留什么核心关系；何时再独立检查 |
| 家长核对 | 最低解释证据、按需提示、出错后回看的位置 |

孩子正文可按这个顺序组织：说明本节要解决的问题，接上熟悉的模型，完整推演一个小例子，比较最容易混淆的情况，归纳可执行动作，再交给孩子一个独立任务。所需篇幅随理解难度调整，一个专题可以跨页、分次学习。

可直接复用的备课请求：

> 请先读取项目 AGENTS.md、编程学习记忆和《小题讲义编写与复用方法》，根据本次题目或知识范围及孩子实际作答备课。先诊断共同卡点，再按理解依赖组织内容。沿用孩子熟悉的模型，从一个具体小例子讲清对象、变量、动作和原因，再用易混对比或反例划清边界。每节提炼一个可执行的检查动作，安排一个完整的独立任务，并设计新情境与延迟复测。孩子的任务答案、提示和核对依据放在分开的家长部分；反思和掌握状态留给真实学习证据。已有专题直接修订原文档，并说明打印变动页。交付前检查每句话与下一句话是否连得起来。

## 交付前的检查

- 能指出本节对应的实际卡点或学习目标，原题与专题可以相互定位。
- 新术语前有可理解的情境；图、表、变量和代码指向同一个过程。
- 具体例子足以支持后面的结论，关键因果没有跳步。
- 相近概念的区别和结论的适用条件讲清楚了。
- 独立任务能区分模仿与理解，孩子有完整的思考空间。
- 家长核对要求的是理由与证据，提示不一次全部给出。
- 反思未代写，掌握状态未预填，复测与补学有明确去向。
- 需要实现时安排关键、最小与边界自测；时间、空间及整数范围等条件与结论一致。
- 网页和打印稿中的图表、代码、答案分区可用；修订归位，打印变动可追踪。
- 学习量纳入已有安排，疲劳时有可以停下的完整小节点。
